# Health & Resource System

> **Status**: Designed
> **Author**: User + Claude
> **Last Updated**: 2026-03-22
> **Implements Pillar**: Pillar 1 — Your Journey, Your Pace (configurable regen)

## Overview

The Health & Resource System tracks current HP, class-specific resource pools
(Mana, Rage, Energy, etc.), and their regeneration over time. It receives damage
and healing events, applies them to current values, and emits threshold signals
(Near-Death at 15% HP, death at 0 HP). Maximum values are calculated by the
Character Stats system -- this system owns current values, regeneration rates,
and state transitions. HP regeneration rate is a user-configurable comfort
setting, respecting Pillar 1.

## Player Fantasy

The player should feel **resilient but not invincible**. HP should matter -- taking
damage creates tension, healing creates relief. But the game should never feel
punishing between encounters. The configurable regen rate lets each player find
their sweet spot: hardcore players who savor the tension of low HP, or casual
players who want to always enter the next fight fresh. Class resources should feel
like a **rhythmic puzzle** -- managing mana/rage/energy is part of the rotation
mastery, not a frustration.

## Detailed Design

### Core Rules

**1. Health (HP)**
- Current HP tracked as integer, clamped between 0 and max_hp
- max_hp calculated by Character Stats (see character-stats.md formulas)
- Damage reduces current HP. Healing increases current HP. Both clamped.
- HP does not go below 0 (no negative HP)

**2. HP Regeneration (User-Configurable)**

| Preset | In-Combat Regen | Out-of-Combat Regen | Default? |
|--------|----------------|--------------------|---------|
| None | 0 | 0 (potions/abilities only) | No |
| Slow | 0 | 1% max HP/sec | Yes (default) |
| Moderate | 0 | 3% max HP/sec | No |
| Fast | 0 | 10% max HP/sec (full in ~10s) | No |
| Always | 0.5% max HP/sec | 5% max HP/sec | No |

- Out-of-combat regen starts after OOC_REGEN_DELAY seconds of not taking/dealing damage
- In-combat regen (only on "Always" preset) ticks continuously
- Regen is paused during Near-Death slow-mo (time_scale affects it)
- Player can change regen preset at any time in Settings

**3. Class-Specific Resources**

Each class has a unique resource type with distinct generation mechanics:

| Resource | Class Archetype | Generation | Depletion | Regen |
|----------|---------------|------------|-----------|-------|
| **Mana** | Caster (Mage, Healer) | Passive regen over time | Spent on abilities | MANA_REGEN_RATE per second, scales with INT |
| **Rage** | Melee (Warrior, Berserker) | Generated by dealing/taking damage | Spent on abilities, decays out of combat | RAGE_GAIN_ON_HIT / RAGE_GAIN_ON_DAMAGE_TAKEN. Decays at RAGE_DECAY_RATE |
| **Energy** | Agile (Rogue, Ranger) | Fast passive regen (fixed rate) | Spent on abilities | ENERGY_REGEN_RATE per second (fast, constant) |
| **Focus** | Tactical (Hunter, Summoner) | Generated by basic attacks | Spent on special abilities | FOCUS_GAIN_ON_BASIC_ATTACK. No decay. |

- Resource type is determined by active class (Class & Mastery System)
- When switching class, resource type changes and resets to: Mana = full, Rage = 0, Energy = full, Focus = 0
- max_resource calculated by Character Stats (base + primary attr scaling + gear + mastery)

**4. HP Threshold Signals**

| Threshold | Signal | Consumer |
|-----------|--------|----------|
| HP drops below 15% max | `near_death_entered` | Input System (triggers slow-mo) |
| HP rises above 20% max | `near_death_exited` | Input System (ends slow-mo) |
| HP reaches 0 | `player_died` | Input System (Dead state), respawn flow |
| HP changes (any) | `hp_changed(current, max)` | HUD System (health bar update) |
| Resource changes (any) | `resource_changed(current, max)` | HUD System (resource bar update) |

**5. Damage and Healing Application**

```
apply_damage(amount):
    current_hp = max(0, current_hp - amount)
    emit hp_changed
    if current_hp / max_hp < 0.15 and not near_death:
        emit near_death_entered
    if current_hp == 0:
        emit player_died

apply_healing(amount):
    current_hp = min(max_hp, current_hp + amount)
    emit hp_changed
    if current_hp / max_hp > 0.20 and near_death:
        emit near_death_exited
```

Damage and healing events come from: Damage Calculation system, potions
(Inventory/consumables), abilities (heal spells), regeneration ticks,
environmental damage (fall damage from Player Controller).

**6. Death and Respawn**
- On death (HP = 0): emit player_died signal
- Input System handles Dead context (respawn UI)
- Respawn at Waypoint: set current_hp = max_hp, teleport to waypoint
- Respawn Potion: set current_hp = max_hp * RESPAWN_POTION_HP_PERCENT,
  apply invulnerability buff for RESPAWN_INVULN_DURATION
- No XP loss, no item loss

### States and Transitions

| State | Entry | Exit | HP Regen | Resource Regen |
|-------|-------|------|----------|---------------|
| Alive (In Combat) | Enemy aggro | All enemies dead/deaggro, after OOC_DELAY | Per preset (usually 0) | Per resource type rules |
| Alive (Out of Combat) | OOC_DELAY after last combat action | Enemy aggro | Per preset | Per resource type rules |
| Near-Death | HP < 15% max (in combat) | HP > 20% max or HP = 0 | Paused (time_scale) | Paused (time_scale) |
| Dead | HP = 0 | Respawn selected | None | None |

### Interactions with Other Systems

| System | Direction | Interface |
|--------|-----------|-----------|
| **Character Stats** | Upstream | Reads max_hp and max_resource. Recalculates when stats change (gear, mastery, Power Level). |
| **Damage Calculation** | Upstream | Receives damage events (amount, type, source). |
| **Input System** | Downstream | Emits near_death_entered/exited and player_died signals. |
| **Ability Rotation Combat** | Both | Abilities consume resource. Some abilities heal HP. Combat state determines regen mode. |
| **Status Effects** | Upstream | Buffs/debuffs can modify regen rates, apply DoTs (periodic damage), or apply HoTs (periodic healing). |
| **Inventory (Consumables)** | Upstream | Potions apply healing or resource restoration. Respawn Potion triggers on death. |
| **Player Controller** | Upstream | Fall damage is applied as a damage event. |
| **HUD System** | Downstream | Emits hp_changed and resource_changed for bar updates. |
| **Enemy AI** | Downstream | Enemy health uses the same system (instanced per entity). |
| **Pet System** | Downstream | Pet health uses the same system (instanced per pet). |
| **Save/Load** | Both | Current HP and resource saved. Regen preset saved in settings. |
| **Settings System** | Upstream | HP regen preset read from user settings. |

## Formulas

### HP Regeneration

```
hp_regen_per_tick = max_hp * REGEN_RATE_PRESET * delta
```

| Preset | REGEN_RATE | Effective (1000 max HP) |
|--------|-----------|----------------------|
| None | 0.0 | 0 HP/sec |
| Slow | 0.01 | 10 HP/sec (full in 100s) |
| Moderate | 0.03 | 30 HP/sec (full in 33s) |
| Fast | 0.10 | 100 HP/sec (full in 10s) |
| Always (OOC) | 0.05 | 50 HP/sec |
| Always (IC) | 0.005 | 5 HP/sec |

### Mana Regeneration

```
mana_regen = MANA_BASE_REGEN + (intellect * MANA_INT_SCALING)
```

| Variable | Default | Description |
|----------|---------|-------------|
| MANA_BASE_REGEN | 2.0/sec | Base mana regen |
| MANA_INT_SCALING | 0.05/sec per INT | INT bonus to mana regen |

### Rage Generation and Decay

```
rage_on_hit = BASE_RAGE_PER_HIT + (damage_dealt * RAGE_DAMAGE_SCALING)
rage_on_taken = damage_taken * RAGE_TAKEN_SCALING
rage_decay = RAGE_DECAY_RATE per second (out of combat only)
```

| Variable | Default | Description |
|----------|---------|-------------|
| BASE_RAGE_PER_HIT | 5 | Flat rage per hit dealt |
| RAGE_DAMAGE_SCALING | 0.1 | Bonus rage per point of damage dealt |
| RAGE_TAKEN_SCALING | 0.2 | Rage per point of damage taken |
| RAGE_DECAY_RATE | 3/sec | Out-of-combat rage loss |

### Energy Regeneration

```
energy_regen = ENERGY_REGEN_RATE  (constant, always active)
```

| Variable | Default | Description |
|----------|---------|-------------|
| ENERGY_REGEN_RATE | 10/sec | Fast, constant regen |

### Focus Generation

```
focus_on_basic_attack = FOCUS_PER_BASIC
```

| Variable | Default | Description |
|----------|---------|-------------|
| FOCUS_PER_BASIC | 10 | Focus gained per basic attack |

## Edge Cases

| Scenario | Expected Behavior | Rationale |
|----------|------------------|-----------|
| Healing when at full HP | Clamped to max. No overheal. | Simple, no overhealing mechanic |
| Damage while invulnerable (Respawn Potion) | Damage blocked entirely. No HP change. | Invuln means invuln |
| DoT ticks during Near-Death | Damage applied at slow-mo rate (time_scale affects tick timing). Quick items still full speed. | Consistent with Near-Death design |
| HoT ticks player above 20% during Near-Death | near_death_exited emitted, slow-mo ends smoothly | From Input System edge case: hysteresis at 20% |
| Regen preset changed mid-combat | Takes effect immediately. No delay. | Player comfort setting, respect instantly |
| Class switch resets resource | Mana/Energy start full. Rage/Focus start at 0. | Match resource generation model |
| Multiple damage events same frame | Applied sequentially. Each checks thresholds. | Prevents skipping Near-Death |
| Exactly 15% HP | Near-Death triggers (< 15% means below, = 15% is AT threshold -- trigger) | Use <= for entry check |
| Fall damage kills player | Normal death flow. Respawn Potion available. | From Player Controller GDD |
| Enemy uses same system | Enemies have HP but no Near-Death, no regen presets. Simplified instance. | Shared code, different config |

## Dependencies

| System | Direction | Hard/Soft | Nature |
|--------|-----------|-----------|--------|
| **Character Stats** | Upstream | Hard | Cannot calculate max HP or max resource without stats |
| **Damage Calculation** | Upstream | Soft | Receives damage events. System works for healing/regen without it. |
| **Input System** | Downstream | Hard | Near-Death and death signals are critical |
| **Ability Rotation Combat** | Both | Soft | Abilities consume/generate resource. Heal abilities restore HP. |
| **Status Effects** | Upstream | Soft | DoTs/HoTs modify HP. Buffs modify regen. Works without. |
| **Inventory (Consumables)** | Upstream | Soft | Potions heal HP/resource. Works without (just no potions). |
| **Player Controller** | Upstream | Soft | Fall damage. Works without (no environmental damage). |
| **HUD System** | Downstream | Soft | HP/resource bar display. Game works without HUD. |
| **Settings System** | Upstream | Soft | Regen preset. Uses default (Slow) if settings unavailable. |
| **Save/Load** | Both | Hard | Must persist current HP, resource, and regen preference. |

## Tuning Knobs

| Parameter | Default | Safe Range | Increase | Decrease |
|-----------|---------|------------|----------|----------|
| OOC_REGEN_DELAY | 5.0s | 2.0-15.0 | Longer wait before regen starts | Faster recovery start |
| MANA_BASE_REGEN | 2.0/s | 0.5-5.0 | Casters spam more | Mana management matters more |
| MANA_INT_SCALING | 0.05/s/INT | 0.01-0.1 | INT more valuable for casters | INT less impactful on regen |
| BASE_RAGE_PER_HIT | 5 | 2-15 | Warriors build rage faster | Rage feels scarce |
| RAGE_DECAY_RATE | 3/s | 1-10 | Rage drains fast OOC | Rage lingers between pulls |
| ENERGY_REGEN_RATE | 10/s | 5-20 | Rogues can ability-spam | Energy management matters |
| FOCUS_PER_BASIC | 10 | 5-20 | Hunters build Focus fast | More basic attacks needed |
| RESPAWN_POTION_HP | 50% | 25-75% | Safer revive | Riskier revive |
| RESPAWN_INVULN_DURATION | 3.0s | 1.0-5.0 | More safety after revive | Less safety |
| NEAR_DEATH_ENTER | 15% | 5-30% | Earlier warning | Less warning (from Input System) |
| NEAR_DEATH_EXIT | 20% | ENTER+5% to 40% | Must heal more to exit | Exits sooner (from Input System) |

**Note**: Near-Death thresholds are owned by Input System's tuning knobs. Listed
here for cross-reference only.

## Visual/Audio Requirements

| Event | Visual | Audio | Priority |
|-------|--------|-------|----------|
| HP decreases | Health bar animates down, red flash on character | Hit impact sound (from combat) | HIGH |
| HP increases (heal) | Health bar animates up, green glow on character | Healing chime | HIGH |
| HP regen tick | Health bar slowly fills | None (silent regen) | LOW |
| Resource consumed | Resource bar animates down | Ability-specific SFX | MEDIUM |
| Resource generated (Rage/Focus) | Resource bar animates up, resource-colored pulse | Subtle resource gain sound | MEDIUM |
| Near-Death enter | (Handled by Input System -- vignette, heartbeat) | (Input System) | HIGH |
| Death | Screen fade to dark | Death SFX, music fade | HIGH |
| Respawn | Flash of light, HP bar fills | Revival chime | HIGH |

## UI Requirements

| Information | Location | Update | Condition |
|-------------|----------|--------|-----------|
| HP bar (current/max) | HUD, prominent | Every hp_changed event | Always in gameplay |
| Resource bar (current/max) | HUD, below HP bar | Every resource_changed event | Always in gameplay |
| HP number (optional) | Inside or beside HP bar | On change | User preference |
| Regen preset indicator | Settings only | On change | Settings menu |
| Enemy HP bar | Above enemy or HUD (when locked on) | On damage | Enemy targeted/locked |

## Acceptance Criteria

- [ ] Current HP tracks correctly, clamped between 0 and max_hp
- [ ] max_hp recalculates when Character Stats change (gear, mastery, Power Level)
- [ ] All 5 regen presets work correctly with specified rates
- [ ] Regen preset changeable in Settings, takes effect immediately
- [ ] Out-of-combat regen starts after OOC_REGEN_DELAY
- [ ] Near-Death signal emitted at HP <= 15%, exit signal at HP > 20%
- [ ] Death signal emitted at HP = 0
- [ ] Respawn Potion restores correct HP% and applies invulnerability
- [ ] Mana regenerates passively, scales with INT
- [ ] Rage generates on dealing/taking damage, decays out of combat
- [ ] Energy regenerates at constant rate
- [ ] Focus generates on basic attacks only
- [ ] Class switch resets resource (Mana/Energy full, Rage/Focus zero)
- [ ] Regen pauses during pause (time_scale=0)
- [ ] Enemy and Pet instances use the same HP system with different configs
- [ ] Performance: HP/resource update within 0.5ms per frame for all entities
